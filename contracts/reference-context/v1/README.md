# Historical compact-context reference v1

- `reference.schema.json` binds complete row-major compact contexts generated by
  the immutable copied TidyCell source under network-denied relocation.
- `parity.schema.json` binds the standalone candidate source closure and exact
  equality for four contexts across the three synthetic workbooks.

```sh
npx tsx scripts/freeze-source-compact-context-reference.ts \
  --bundle reference/source-closures/sha256-... \
  --output fixtures/reference-context/historical-v1.json \
  --recorded-at 2026-08-11T22:30:00Z
```

The worker emits `compact-context.json` only when
`includeCompactContext: true`. The bounded context scope has parity, but prompt
assembly, formatting facts, catalogue evidence, produced-CSV summaries,
independent review, and full Phase C parity remain incomplete.
