# Historical role-aware region catalogue reference v1

- `reference.schema.json` binds complete V5 role-aware catalogues generated by
  the immutable copied TidyCell source under network-denied relocation.
- `parity.schema.json` binds the standalone candidate source closure and exact
  equality for four catalogues across three synthetic workbooks.

```sh
npx tsx scripts/freeze-source-region-catalog-reference.ts \
  --bundle reference/source-closures/sha256-... \
  --output fixtures/reference-region/historical-v1.json \
  --recorded-at 2026-08-12T03:50:00Z
```

The worker emits `region-catalog.json` only when
`includeRegionCatalog: true`. This establishes the bounded historical default
catalogue scope, not rendered prompt parity, independent review, or full Phase C
parity.
