## Required oracle representation

The production oracle must be an explicit address table, not a regex or surrounding-proof heuristic. Each rule must contain:

```text
memberId
source workbook digest + physical sheet + authoritative range
target selector (exact address/range)
asserted source row/column/panel/parent-header address and exact raw value
observation-period binding ID
semantic role and explicit canonical dimension assignment
measure + statistic + unit
counting unit + population basis + denominator
entity universe + transfer treatment
row classification + principal-offence classification + Federal Offence Group classification
classification treatment + principal-selection version
sentence classification treatment + revision treatment
hierarchy level + total/subtotal/leaf status
exact source-note references
perturbation=true
```

Every `asserted ... raw value` must be checked before generation. No rule may search arbitrary nearby proof text, infer from a substring such as `court level`/`Total`, derive a footnote from punctuation alone, or use row ordinal/source coordinate as a semantic discriminator. Coordinates are authority/provenance, not category IDs. Exact style and indentation are retained and independently checked only as raw source proof; they never execute a semantic assignment.

The oracle root is a closure manifest, not a self-authenticating trust anchor. Independent verification requires its SHA-256 as an external argument. The reviewed Git commit that eventually adds these Boundary-1 files is the immutable anchor for that literal digest; until that commit exists, the generated root remains an inert review artifact.

Generation is fail-closed: the verifier rejects every incomplete or mismatched manifest/shard combination. Individual files and the complete shard directory are replaced atomically, but the shard-directory replacement and separate manifest replacement are not a single cross-path filesystem transaction. An interruption between them can leave an invalid corpus that deterministically fails verification; Boundary 1 does not claim whole-corpus transactional publication.
